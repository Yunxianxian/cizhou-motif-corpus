# 磁州窑数智化图案语料库 · 移动端网页原型

按你提供的四张设计稿实现的可交互手机网页：**首页（一级）→ 装饰列表（二级）→ 纹样详情（三级）**，
以及底部「我的」（一级）与其下的全部次级页面。除设计稿已有的界面外，补齐了首页与「我的」中
隐含但未出图的页面（搜索、工艺图谱、展览信息、关注 / 收藏 / 历史 / 我的上传 / 本地下载 / 更多服务等）。

零依赖、零构建：纯 HTML + CSS + 原生 JS（经典 `<script>`，非 ES Module），
**直接双击 `index.html` 即可打开**，也可用附带的本地服务器预览。

> 想在手机本地打开、不装服务器、不联网？用 **`手机/磁州窑纹样语料库.html`**——
> 一个把 CSS/JS 全部内联的自包含单文件，拷到手机点开就能用。详见第 1.1 节。

## 1. 如何打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 直接打开 | 双击 `index.html` | 无需服务器；`file://` 下 localStorage 可能被浏览器限制，状态保存会失效 |
| 本地服务器（推荐） | `node tools/serve.mjs 5178` → 打开 <http://localhost:5178/> | 完整功能（收藏、关注、历史、主题等本地状态可持久化）；默认监听 `0.0.0.0`，启动时会打印手机可用的局域网地址 |
| 手机预览 | 同一 Wi-Fi 下访问 `http://<电脑IP>:5178/` | 宽度 < 620px 时自动切换为全屏 App 形态（隐藏机身外壳与假状态栏，使用安全区留白） |

桌面宽度下页面外会显示手机外壳与说明面板；窗口变矮时整机会等比缩放，始终完整可见。

### 在手机上打开（详细步骤）

1. **电脑和手机连同一个 Wi-Fi**。
2. 电脑上执行 `node tools/serve.mjs 5178`，终端会打印可用地址：

   ```
   静态目录: D:\作品集\1x\网页
   本机访问: http://localhost:5178/
   手机访问（同一 Wi-Fi 下用浏览器打开）:
     http://10.0.175.4:5178/
   ```
3. 手机浏览器打开上面那条 `http://10.0.x.x:5178/` 地址。
4. 首次 Windows 会弹防火墙提示，勾选「专用网络」并允许，否则手机连不上。
5. 打开后点浏览器菜单里的「**添加到主屏幕**」：项目已带 `manifest.webmanifest` 与
   180 / 192 / 512 三种尺寸图标，加完即为**全屏、无地址栏**的独立应用形态
   （iOS 走 `apple-mobile-web-app-capable`，Android 走 manifest 的 `display: standalone`）。

> 连不上通常是两种原因：Wi-Fi 开了「AP 隔离」（公司/校园常见），或防火墙未放行。
> 临时办法是用**手机开热点、让电脑连热点**，再用终端打印的地址访问。

**部署到公网**：本项目是纯静态站点，把整个文件夹拖到 Netlify Drop / Vercel，或推到 GitHub Pages 即可，
手机随时访问、也能直接分享链接（上传时带上 `assets/` 与 `manifest.webmanifest`）。

### 1.1 手机本地运行版（单文件，推荐给手机用）

`手机/磁州窑纹样语料库.html` 是把上面所有 CSS / JS **内联进同一个文件**的自包含版本：

```
手机/
  磁州窑纹样语料库.html    约 279 KB，单文件、零外部依赖，可离线打开
  使用说明.txt             拷到手机 / 打开 / 添加到主屏幕的步骤说明
```

- **不需要服务器、不需要联网**，也不怕漏拷 `assets/` 子目录——只传这一个文件就够
- 手机上打开方式：微信「文件传输助手」发到手机 → 点开 → 用浏览器打开
  （Android 也可直接在 Chrome 地址栏输入 `file:///sdcard/Download/磁州窑纹样语料库.html`）
- 打开后在浏览器菜单里「添加到主屏幕」，即为全屏无地址栏的应用形态
- **已验证**：`file://` 下页面渲染、卡片→详情、返回、底部 Tab 切换、主题切换全部正常
  （本地文件下浏览器会拒绝 `history.pushState`，路由已内置退化为改 `hash` 的方案）
- 注意：iPhone 的 Safari 会禁止本地网页保存数据，收藏 / 主题等设置只在本次打开期间有效；
  想长期保存就用本地服务器或公网部署方式打开。`store.js` 会自动退化为内存状态，不会报错

改完源文件后重新生成单文件版（在项目根目录执行）：

```powershell
node tools/build-single.mjs
```

**URL 参数**：`index.html?theme=dark`（`light` / `dark` / `sepia`）、`index.html?font=1.08`（`1` / `1.08` / `1.16`），
可在不进入设置页的情况下直接预览主题与字号。

## 4. 交互与动效清单

**转场**
- 前进 / 返回：页面左右推入推出（前页视差退场），缓动 `cubic-bezier(.32,.72,0,1)`
- Tab 切换：淡入 + 轻微缩放，底部胶囊滑动跟随（`cubic-bezier(.34,1.36,.5,1)` 回弹）
- 屏幕左缘右滑返回：跟手位移 + 前页实时显现，松手按位移/速度判定，可中途取消回弹
- 卡片 → 详情：**共享元素转场**，卡片图形飞向详情主图位置并同步淡出（`prefers-reduced-motion` 下自动关闭）

**首页**
- 大图轮播：自动播放 5.2s、手势拖动跟手、拖动距离判定翻页、点击圆点跳转、切换时标题字距动画
- 滚动联动：顶部栏由「透明 + 白字 + 大字」渐变为「毛玻璃 + 墨字 + 小字」，轮播视差上移、标题与圆点渐隐
- 分类横滑：边缘渐隐遮罩，滚动到末端自动取消遮罩
- 下拉刷新：橡皮筋跟手 + 墨点指示器（下拉刷新 / 松开刷新 / 正在更新语料三态）

**列表 / 搜索**
- 分类筛选：标签切换 + 骨架屏占位 + 卡片错峰入场
- 触底自动加载（每批 9 件，3 列网格），加载完提示「已显示全部 N 件纹样」
- 长按卡片：弹出快捷操作面板（详情 / 收藏 / 下载高清图 / 分享）
- 搜索：180ms 防抖实时检索纹样、工艺、展览三组结果，搜索历史可清空

**详情**
- 图版切换：线稿 / 器物 / 瓶罐 / 瓷片 / 范本五种视图，交叉淡入淡出
- 右下角收藏浮标：吸底吸附 + 星标回弹动画，状态写入本地存储
- 「···」动作面板：收藏、关注该纹样分类、下载、同款实物照片、分享、纠错
- 语料范本长文折叠展开；同主题纹样横滑推荐

**我的**
- 公告跑马灯、快捷宫格按压反馈、昵称修改（本地存储）、消息与徽章面板
- 主题更换：浅色 / 深色 / 宣纸三套主题即时切换（`html[data-theme]`），正文字号三档、动效开关
- 上传：三步流程指示，可选真实本地图片（`URL.createObjectURL` 预览）或从素材库选择，提交后进入审核中状态
- 本地下载：进度条动画、存储占用统计、下载 / 删除状态同步

**通用**
- 分层动作面板（可下拉关闭）、确认对话框、Toast、骨架屏、空状态插画
- 长按 / 按下 / 抬起反馈、震动反馈（`navigator.vibrate`，可用时）
- 无障碍：`aria-label` / `role` / `aria-selected`，`:focus-visible` 焦点环，跟随系统「减少动态效果」

## 6. 把占位图形换成真实照片

页面里所有纹样、器物、窑址场景、首页大图都是**程序化生成的水墨矢量图**（`ornament.js`），
它们只是占位，替换成馆藏照片不需要改任何视图代码：

1. 把照片放进 `assets/img/`（建议纹样图正方形、白底、边长 ≥ 1000px）。
2. 在 `assets/js/photos.js` 中登记：

```js
CZ.Art.photos.motif['plant-mudan-01'] = 'assets/img/plant-mudan-01.jpg'; // 纹样（列表卡片、详情主图、缩略图共用）
CZ.Art.photos.scene.kiln              = 'assets/img/kiln.jpg';            // 工艺场景：kiln/workshop/wheel/saggars/shards/glaze/clay/museum/fuel
CZ.Art.photos.hero.h1                 = 'assets/img/hero-museum.jpg';     // 首页轮播大图：h1…h5
```

3. 也可以直接给 `data.js` 中的某件纹样加 `photo` 字段（优先级高于 `photos.js`）。

未登记的条目会继续使用矢量占位图，可以一张一张替换。纹样图使用 `object-fit: contain`（完整显示），
场景图与大图使用 `cover`（铺满裁切）。详情页的「线稿」视图始终由矢量生成，不受照片影响。

## 8. 浏览器支持

面向现代移动浏览器（iOS Safari 16+ / Chrome 110+ / 微信内置浏览器）。
使用了 `aspect-ratio`、`backdrop-filter`、`dvh`、Web Animations API、`scrollbar-width` 等特性；
在不支持 `backdrop-filter` 的浏览器上会退化为不透明背景，功能不受影响。
