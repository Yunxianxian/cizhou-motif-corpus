# 磁州窑数智化图案语料库

纯 HTML、CSS、原生 JavaScript 的手机端交互网页。浅色主题采用纯白背景，导航使用灰色液态玻璃效果；支持深色、宣纸主题。

底部选中胶囊支持按住放大、左右拖动，松手后吸附到最近的导航项并进入对应一级页面。普通点击与键盘操作继续可用；拖动中断时返回原选中项。

## 打开网页

- 电脑：双击根目录的 `index.html`。
- 手机离线：复制 `手机/磁州窑纹样语料库.html`，单个文件即可使用，图片与代码均已内嵌。
- 同一 Wi-Fi 预览：在项目根目录执行 `node tools/serve.mjs 5178`，访问终端打印的地址。

## 当前纹样

“植物装饰”已收录用户提供的全部 **121 张图片**：牡丹纹 80 张、卷草纹 10 张、缠枝纹 31 张。牡丹纹分类以原始 `mudanwen` 与 `white mudanwen` 文件夹为准。条目保留既有 ID，兼容收藏、历史和详情链接。

器物出处、年代、工艺、展讯等文字仍为原有界面演示文案，未根据新图片核实。

## 图片浏览

“我的”页在“我常看的纹样”上方提供项目总结报告入口。报告采用概览、章节／研究专题、小节展开三层阅读结构，包含七章主报告、两篇研究成果、心得致谢及参考文献与项目附件。报告图表可点击全屏放大，手机离线版已包含正文与配图；项目附件为原报告中的外部链接，需要联网访问。

点击纹样详情主图、相关语料图片或语料范本图片可全屏查看。支持双指缩放、放大后拖动、双击缩放、原始大小时左右滑动切换图版；底部提供上一张、下一张、放大、缩小与重置按钮。电脑可用滚轮缩放、方向键切换、Esc 关闭。

正文、图片和内容卡片使用实色底，玻璃效果集中于导航、操作按钮与弹出面板；浅色主题的阅读区域为纯白。

## 修改与构建

修改 `index.html` 或 `assets/` 后，在根目录执行：

```powershell
node tools/build-single.mjs
```

这会重新生成 `手机/磁州窑纹样语料库.html`；请在源文件中修改，避免直接编辑生成文件。

图片映射在 `assets/js/photos.js`，网页条目与分类在 `assets/js/data.js`。原图到网页素材的对应关系见 `assets/img/patterns/sources.json`。

## 辅助工具

- `tools/serve.mjs`：本地静态服务器。
- `tools/build-single.mjs`：生成手机离线单文件。
- `tools/check-viewer.mjs`：检查图片查看器的手势、缩放边界、键盘和关闭清理逻辑，执行 `node tools/check-viewer.mjs`。
- `tools/check-tabbar.mjs`：检查底部胶囊的按住放大、拖动吸附、取消、缩放坐标与点击兼容逻辑，执行 `node tools/check-tabbar.mjs`。
- `tools/organize-patterns.py`：按原始素材建立整理副本与浏览索引，需要 Python / Pillow；该工具中的旧“花种待核对”提示为早期视觉检查记录，网页分类以用户确认的原文件夹为准。
- `tools/make_icons.py`：生成应用图标。
- `tools/shots.ps1`、`tools/routes*.json`：批量截图工具；运行时会重新创建截图输出文件夹。
- `tools/deploy-ghpages.mjs`：现有 GitHub Pages 发布工具，仅保留，本次未执行发布。
