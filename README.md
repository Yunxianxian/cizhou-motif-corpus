# 磁州窑数智化图案语料库

纯 HTML、CSS、原生 JavaScript 的手机端交互网页，零依赖、零构建。

- **线上地址**：<https://yunxianxian.github.io/cizhou-motif-corpus/>
- **仓库**：<https://github.com/Yunxianxian/cizhou-motif-corpus>
- **当前版本**：v1.2.0（内测）

浅色主题采用纯白背景，导航使用灰色液态玻璃；支持深色、宣纸主题。底部选中胶囊支持按住放大、左右拖动，松手后吸附到最近的导航项并进入对应一级页面；普通点击与键盘操作继续可用，拖动中断时返回原选中项。

## 打开网页

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 线上 | 直接访问上面的线上地址 | 手机 / 电脑均可，推荐分享这个链接 |
| 电脑本地 | 双击根目录 `index.html` | 无需服务器；`file://` 下浏览器可能限制本地存储，收藏与主题保存会失效 |
| 本地服务器（推荐） | `node tools/serve.mjs 5178` | 访问终端打印的地址；默认监听 `0.0.0.0`，同一 Wi-Fi 下手机也能打开 |

“我的”页在“我常看的纹样”上方提供项目总结报告入口。报告采用概览、章节／研究专题、小节展开三层阅读结构，包含七章主报告、两篇研究成果、心得致谢及参考文献与项目附件。报告图表可点击全屏放大。项目附件为原报告中的外部链接，需要联网访问。

## 图片浏览

点击纹样详情主图、相关语料图片、语料范本图片或报告图表可全屏查看。支持双指缩放、放大后拖动、双击缩放、原始大小时左右滑动切换图版；底部提供上一张、下一张、放大、缩小与重置按钮。电脑可用滚轮缩放、方向键切换、Esc 关闭。

正文、图片和内容卡片使用实色底，玻璃效果集中于导航、操作按钮与弹出面板；浅色主题的阅读区域为纯白。

## 交互要点

- **头图轮播**：自动播放 5.2s，可左右拖动跟手翻页。拖动结束后**不会**误触进入该图的链接；轻点仍然正常跳转（`assets/js/view-home.js`）。
- **横向横幅**（装饰分类 / 展览与活动 / 创新应用）：触屏走浏览器原生惯性滑动；桌面鼠标可**按住拖动**滚动（`assets/js/hscroll.js`）。已禁用标签与图片的原生拖拽，否则拖动会变成“拖出一张图”而中断滚动。
- **不做滚动吸附**：所有横向横幅均为自由滚动，松手后不会回弹到卡片边界。
- **底部导航胶囊**：按住放大、左右拖动，松手吸附到最近项。
- **左缘右滑返回**：在距屏幕左缘 32px 内起手，非首页时可用。

- 文字与条目：`assets/js/data.js`

页面不经过构建，改完源文件刷新即可生效。

## 发布（GitHub Pages）

线上站点由 `tools/deploy-ghpages.mjs` 通过 GitHub REST API 直接推送，**不需要安装 git**。

```powershell
$env:GH_TOKEN="<有 repo 权限的 Token>"
node tools/deploy-ghpages.mjs --repo cizhou-motif-corpus --message "update: 说明"
```

- 脚本会完成：建仓（已存在则复用）→ 逐个上传 → 建 tree / commit → 更新 `main` → 开启 Pages → 轮询构建状态。
- `--dry-run` 只列出将要上传的文件，不发任何请求。
- **提交以整棵树替换线上内容**：本地删掉的文件，线上也会消失。
- 发布排除项写在脚本的 `SKIP_DIRS` 里，增减目录改那一处即可。

当前排除（不发布到线上）：

| 目录 | 原因 |
| --- | --- |
| `手机/` | 单文件版已停止维护，体积也大 |
| `纹样图片/` | 原始素材，网页不引用 |
| `参考截图/` | 设计参考图，网页不引用 |
| `dev/review-shots/` | 过程截图 |

发布内容约 **279 个文件 / 20.9 MB**。首次生效通常 1–2 分钟；新增文件刚推送后可能短暂 404，属于 CDN 传播延迟，不是发布失败。

## 说明与限制

- **文案为演示数据**：器物出处、年代、工艺、展讯等描述均为界面演示用的示例文案，正式上线前应替换为馆方审核后的学术数据与真实展讯。
- **手机单文件版已停止维护**：`手机/磁州窑纹样语料库.html` 是早期的离线自包含版本，内容停留在旧版本，不再随源码重新生成，也不发布到线上。需要手机离线使用请以线上地址或本地服务器为准。
- **配图**：纹样与器物图使用黑白摄影素材，正式发布前建议替换为博物馆授权的馆藏照片。
