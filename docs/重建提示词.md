## 1. 任务定义

你要从零实现一个**移动端网页 App 原型**：「磁州窑数智化图案语料库」。
它是中国磁州窑（以"白地黑花"著称的古代民窑）纹样的检索与浏览应用，
信息架构为：**首页（一级）→ 装饰列表（二级）→ 纹样详情（三级）**，外加底部「我的」（一级）及其全部次级页面。

**硬性约束（不可违反）**

1. **零依赖、零构建**：纯 HTML + CSS + 原生 JavaScript（经典 `<script>` 标签，非 ES Module），
   不引入任何框架 / CDN / npm 包 / 外部字体。双击 `index.html`（file:// 协议）必须能完整运行。
2. 面向现代移动浏览器（iOS Safari 16+ / Chrome 110+），允许使用 `backdrop-filter`、`aspect-ratio`、`dvh`、Web Animations API。
3. 视口按 **390 × 844**（iPhone 标准）设计；窗口宽度 ≥ 620px 时，页面中央显示一部带边框的手机模型，
   App 在手机屏幕内运行；< 620px 时切换为全屏 App 形态（隐藏外壳与假状态栏）。
4. 全部界面文案为简体中文；所有考古描述使用示例文案即可，但信息结构必须完整。
5. 单一代码仓库交付，目录结构见第 4 节。

## 2. 设计语言总纲（最重要，先读三遍）

整体气质 = **黑白摄影 + 博物馆式大留白 + iOS 液态玻璃**。三个关键词：

1. **黑白影像为视觉主角**。头图、分类卡、工艺场景一律使用黑白摄影质感的图片
   （深色、高对比、博物馆射灯氛围），界面本身退后。禁止彩色插画感。
2. **博物馆式大留白**。内容面为纯白（或近白），文字墨色，间距疏朗，衬线字体做点缀，
   类似美术馆展签。不要多彩渐变背景、不要重投影。
3. **iOS 液态玻璃只用于"浮起来的层"**：底部导航栏、吸顶导航、动作面板、对话框、Toast、圆形工具按钮。
   玻璃 = 高透明度 + 强 `backdrop-filter` 模糊与饱和 + 顶部 1px 镜面高光（inset）+ 细折射描边。
   内容滚动经过导航栏下方时必须清晰透出。

辅助气质：鼠标 / 手指掠过玻璃元素时，有一团**跟随指针的镜面光斑**（液态感来源之一）；
动效全部使用带弹性的缓动，见 3.4。

### 三套主题

`html[data-theme]` 切换，全部颜色走 CSS 变量，三套主题共用同一套结构：
- `light`（默认）：纯白博物馆，黑墨文字
- `dark`：窑夜墨色，白字
- `sepia`：宣纸暖米，茶色文字

## 5. 全局骨架

### 5.1 桌面展示外壳（≥620px 才显示）

- 页面背景：陶瓷暖调氛围渐变（浅灰米色多层 radial-gradient + 46px 细网格线）。
- 手机模型：宽 412、高 866、padding 11、圆角 60，深灰金属渐变外壳 + 四颗侧边按键；
  屏幕 390×844、圆角 50、`overflow:hidden`。窗口变矮时整机按 `--k` 等比缩放始终完整可见。
- 假状态栏：高 54，左侧"9:41"，中间灵动岛（118×33 黑胶囊），右侧信号/Wi-Fi/电池 SVG；
  首页大图模式下文字变白（`html[data-hero="1"]` 控制）。底部 home 指示条（138×5）。
- 手机左侧放一块说明面板（标题"磁州窑数智化图案语料库" + 层级说明），<980px 隐藏。
- <620px：外壳、按键、假状态栏全部隐藏，`.device` 变 `100vw × 100vh`（`100vh` 写在 `100dvh` 前兜底）。

### 5.2 底部导航栏（全站最重要的组件，像素级照做）

三个 Tab：**语料库（#/home）· 上传（#/upload）· 我的（#/profile）**。

```css
.tabbar{
  position:absolute; left:12px; right:12px; bottom:12px; height:78px;
  border-radius:30px;
  background:linear-gradient(180deg,var(--g-tab-1),var(--g-tab-2));   /* 高透！ */
  border:1px solid var(--g-brd);
  box-shadow:inset 0 1.5px 0 var(--g-hi), inset 0 -.5px 0 rgba(0,0,0,.05),
             0 18px 44px rgba(20,20,26,.14), 0 3px 10px rgba(20,20,26,.07);
  backdrop-filter:blur(28px) saturate(1.9);
}
.tabbar__pill{           /* 选中胶囊：液态玻璃浮珠 */
  position:absolute; top:12px; height:calc(100% - 24px);
  border-radius:18px;    /* 与 30px 栏同心：30 - 12 = 18，必须对齐 */
  background:linear-gradient(180deg,var(--g-pill-1),var(--g-pill-2));
  border:1px solid var(--g-pill-brd);
  box-shadow:inset 0 1px 0 var(--g-hi), 0 4px 12px rgba(20,20,26,.1);
}
```

- 胶囊位置由 JS 计算：目标 Tab 的 `getBoundingClientRect()`，left = x+5、width = w−10（水平内缩 5px）。
  切换 Tab 时胶囊滑动跟随，缓动 `cubic-bezier(.34,1.36,.5,1)`、380ms。
- Tab 内图标 24px + 下方 10.5px 文字；选中态图标 `translateY(-1.5px) scale(1.08)`（--e-liquid），
  未选中灰色 `--muted`。
- 移动端安全区：`bottom: calc(10px + env(safe-area-inset-bottom))`。

### 5.3 页面骨架与转场

- `.page` 绝对定位铺满屏幕、纵向滚动、隐藏滚动条、`overscroll-behavior-y:contain`。
- 前进：新页从右推入，旧页轻微左移视差退场；返回反之；统一 380ms `var(--e-out)`。
- 屏幕左缘右滑返回：跟手位移 + 前页实时显现，松手按位移/速度判定，可中途取消回弹。
- Tab 切换：淡入 + 轻微缩放（不走左右推入）。
- 页面底部留 `bottomSpace(112)` 给导航栏悬浮空间。

## 7. 逐页面规格

### 7.1 首页 `#/home`（对照设计稿图一）

自上而下：

1. **吸顶栏 `.hometop`**（透明覆盖在大图上）：左侧口号"黑与白的艺术"（白字 70% 透明），
   居中标题"首页"（白色 23px 600 字重、字距 .12em），右侧圆形玻璃搜索钮（38px，半透明黑玻璃白图标）。
   滚动 >44px 后：背景渐变为吸顶玻璃、标题缩小变黑、口号左移淡出。
2. **轮播大图 `.hero`**：高 318px，负 margin 伸到屏幕顶。5 张黑白摄影图（素材见第 11 节），

   （如"中国磁州窑遗址博物馆"）+ 圆点指示器（激活点拉长为 17px 胶囊并带白色微光）。
   自动播放 5.2s、手势拖动跟手、拖动超 18% 翻页、切换时标题做字距呼吸动画；
   滚动时大图视差上移 `y*0.18`、标题圆点渐隐。
3. **白色内容板 `.homesheet`**：`margin-top:-26px`、顶部圆角 26px、纯白背景、
   `box-shadow:0 -14px 34px rgba(10,10,14,.18)` 与大图柔和衔接。
4. **装饰分类横滑**：两张大卡（植物装饰"简练豪放，写意质朴" / 人物装饰"笔底故事，人间情味"），
   每卡宽 61%、标题 23px 在上、下方 4:3 圆角图（黑白瓷面照片，**满铺 cover，无内边距**）；

5. **传统烧制工艺**：章节头（标题 19px + 副标题"一窑一器，薪火不息" + 右侧"全部工艺 ›"）。
   左 1 高右 2 矮的照片九宫格（高约 248px）：窑址拱门（竖图）、拉坯、施釉。
6. **展览与活动**：横滑卡（宽 74%）：16:10 展厅黑白照片 + 标签 + 标题 + 日期。
7. **语料库数据卡**：玻璃圆角卡，4 格统计（1,286 收录纹样 / 342 历史语料 / 12 窑址点位 / 9 工艺工序，
   数字用衬线体），底部一行小字来源说明。
8. **快捷入口** 3 格（检索纹样 / 工艺图谱 / 我的收藏）+ 页脚（细线 + "中国磁州窑遗址博物馆 · 磁州窑数智化图案语料库"）。
9. 下拉刷新：橡皮筋跟手 + 墨点指示器三态动画，完成 Toast"语料已更新至最新"。
