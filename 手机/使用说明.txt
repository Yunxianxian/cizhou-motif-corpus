磁州窑数智化图案语料库 · 手机本地运行版
==========================================

这个文件夹里只有一个网页文件：

    磁州窑纹样语料库.html

样式、脚本、纹样图形全部打包在文件内部，所以：
  · 不需要服务器，不需要联网，打开后完全离线可用
  · 不需要一起拷 assets 之类的子文件夹，单独一个文件就能跑
  · 也可以直接在电脑上双击打开（宽屏下会显示手机外壳预览）


【怎么放到手机上】

方法一：微信 / QQ / 邮件发给自己（最省事）
  1. 电脑上把这个 html 文件用「文件传输助手」发到手机
  2. 手机上点开这个文件 → 选择「用浏览器打开」
     iPhone：先「用其他应用打开 → 存储到文件」，再到「文件」App 里点它
     Android：直接选 Chrome 打开

方法二：数据线拷贝
  iPhone ：拷到「文件」App 的「我的 iPhone」里任意文件夹，点开即可
  Android：拷到 Download 目录，然后在 Chrome 地址栏输入
           file:///sdcard/Download/磁州窑纹样语料库.html

方法三：加到主屏幕（用起来最像 App）
  用浏览器打开后，在浏览器菜单里选「添加到主屏幕」。


【手机上怎么用】

  · 底部三个标签：语料库 / 上传 / 我的
  · 点卡片进入下一级；从屏幕最左边缘往右滑可以返回
  · 长按任意纹样卡片 → 快捷操作（详情 / 收藏 / 下载 / 分享）
  · 详情页右下角星标可以收藏；首页与列表页支持下拉刷新
  · 「我的 → 主题更换」可切换 浅色 / 深色 / 宣纸，正文字号也能调


【关于设置能不能保存】

用本地文件打开时，部分浏览器（尤其 iPhone 的 Safari）会禁止网页保存本地数据。
这种情况下收藏、主题、昵称等设置只在本次打开期间有效，关掉页面就恢复默认——
这是浏览器的安全策略，不影响正常浏览。

想要设置能长期保存，用下面任意一种方式打开：
  · 电脑上执行 node tools/serve.mjs 5178，手机连同一 Wi-Fi 访问终端打印的地址
  · 或把整个文件夹部署到 Netlify / Vercel / GitHub Pages，用 https 链接打开


【两点说明】

  · 内容里的考古描述、窑址与展览信息都是界面演示用的示例文案，正式使用请替换为馆方数据。
  · 纹样与器物图是程序化生成的水墨矢量图，替换成馆藏照片的方法见上一级目录的 README。


【怎么改内容】

单文件版是生成出来的：改上一级目录里的源文件（assets/、index.html），
然后在上一级目录执行：

    node tools/build-single.mjs

就会重新生成这个 html。
